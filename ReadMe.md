## Project Description
This project is a simple command-line calculator written in C. It performs basic arithmetic operations — addition, subtraction, multiplication, and division — based on user input. The program demonstrates fundamental C programming concepts such as variables, and standard input/output handling.

## Input
```
The program takes the following inputs from the user:
1. Lab name
2. Number of computers
3. Number of network devices
4. Number of security tools
5. Cost per computer
6. Cost per network device
7. Annual security software cost
```
## Processing
```
- Calculate:
Computer Cost =
Number of Computers × Cost per Computer
Network Cost =
Number of Network Devices × Cost per Device
Total Lab Investment =
Computer Cost + Network Cost + Software Cost
```

## How to Compile
Open a terminal in the project directory and run:

```bash
gcc -o cyber_lab cyber_lab.c
```

Then execute the compiled program:

```bash
./cyber_lab
```

(On Windows, you can run `cyber_lab.exe` after compiling with GCC or a similar compiler.)
